# Made Solid refinement data

- `origin.json` ties this local repository to its immutable Studio build and package.
- `refinement-log.jsonl` is an append-only record of meaningful, verified corrections.
- `evidence/` may contain private before/after evidence referenced by ledger entries.
- `learning-bundle.json` is generated at a milestone and handed back to Studio for distillation.

Keep this directory private. It may contain client-specific paths and observations. Only distilled,
reusable tests, contracts, components, or guidance belong in the Made Solid Studio repository.
